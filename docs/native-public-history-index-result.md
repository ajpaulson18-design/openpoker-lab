## Prior-production native-only profile

The profile uses clean `a05fe2ade71214c13b6d5100e76b7f2102939ea7`, whose native
production closure matches accepted `a54483e94e3967e1eaa2fc33fe0733e33fa14a58`.
It predates the new index. All 2,049 source files, build/dependency closure and
three original saved wires are authenticated. Exact, recorded textual anchors
add nested timing scopes only to external source copies. Each request gets one
fresh uninstrumented child and one instrumented child. All six exit successfully,
and their complete ROW probability bits and all 13 DONE fields match the original
frozen stdout. A separate saved-only review authenticates all artifacts, reproduces
the source transformation and checks timer partitions without candidate execution.
It does not newly recompute the saved Python diagnostics or add quality certificates.

| Fixture | Uninstrumented process wall | Instrumented process wall | Instrumented run interval | Tagged history exclusive total |

| Original 22-world T10 | 589.2209 ms | 627.7736 ms | 498.5580 ms | 263.7992 ms |
| Asymmetric weighted | 19.7426 ms | 22.2846 ms | 13.1405 ms | 6.6440 ms |
| Mixed stabilizer | 18.5846 ms | 21.4591 ms | 12.2323 ms | 7.0711 ms |

Only exclusive records partition the instrumented run interval. Tagged history
work is 52.91%, 50.56% and 57.81% of those respective intervals, including setup,
preflight and output history work as well as learning. Recursive inclusive times
overlap. In original-fixture learning, lookup self time is 122.2093 ms, separate
reveal parsing 86.6179 ms and root routing 8.6225 ms. Lookup inclusive time
204.6806 ms already contains child phases and cannot be added to them. Exact
terminal callbacks take 130.0488 ms inclusive, including conversion and rank cache.

The observations motivate numeric Q keys and typed prefix access alongside the
incremental cursor; root routing alone is a small part of the measured issue.
They do not separately identify every operation within lookup self time.

Instrumentation adds clocks, record updates, finite-check counters and changes
inlining. Observed wall ratios of 1.0654/1.1288/1.1547 are overhead observations,
not general speedups or causal production CPU shares. Each fixture has one pair,
not a timing distribution. The root interval excludes startup and final profiling
report emission. No Python legal preparation, diagnostics, full-API serialization,
whole-process memory or new-index performance is measured here.

The compile-only first attempt failed on a timer-variable name collision and
made zero candidate calls. The first saved-only review failed its final inventory
check because importing the external helper created a new cache directory. Both
failures and helpers remain. Only the newly generated cache was moved out;
original artifacts were unchanged. The corrected reviewer loads saved definitions
without writing caches and executes no candidate. The original completed profile
was not restarted.
