# Structural per-row regret denominators

The next lossless representation gate passes original independent audits:
each full-history row can use a denominator determined by its remaining own
decisions instead of the global worst depth. This is a proved prospective
carrier and saved-state model, not a native implementation or speed result.
It follows the [compact shared Store](compact-role-persistent-store.md).

## Induction and ownership

Let `d(p,s)` count the maximum remaining player `p` decisions from numeric
source `s`, including `s` if `p` acts there. The independent numeric rules
construct all 388 sources and 410 edges. All 203 terminal sources have
half-unit whole-hand payoffs of magnitude at most eight. For a fixed opponent
ticket transcript, the target value at `s` is a multiple of
`2^-(1+52*d(p,s))`:

- A terminal has own depth zero and a half-unit payoff.
- A reveal or selected opponent action introduces no new policy denominator.
  Child powers embed exactly in the maximum suffix power.
- At an own decision, all own actions remain expanded, including zero-policy
  actions. Mixing integer Q52 units introduces at most 52 bits. Subtracting
  this mixture from a child value gives the same regret denominator bound.

This uses the admitted role cancellation; it is not an arbitrary proposal's
importance-weight bound. No global reach/probability product is formed.
Root own depths are `(6,7)`; regret powers are
`53,105,157,209,261,313,365`. Averages stay at power 52.

For a row of power `e`, canonical R625 divides exactly by `2^(625-e)` and
global compact R365 by `2^(365-e)`. Addition preserves this fixed row scale
across epochs/worlds. Positive scaling preserves exact regret-matching
quotients, remainders and Q52 tie order. This does not admit longer training
or its integer widths/resources. Structural sources supply only bounds:
policies still belong to full History/actor/original-holding keys. The audit
checks literal path/source/actor/menu identity and retains every original
row and policy; numeric continuation sharing never merges information sets.
