## Suit symmetry is conditional opportunity, not shipped compression

The paired club/diamond controls both have 56 supported rows/114 slots. Equal
weights on holdings exchanged by that suit map preserve the whole-input group of
size two and yield 28 row orbits. Breaking those exact weights leaves only the
identity and all 56 rows. The 24-board axis has group size two and 4,716 orbits
among 7,504 rows; the 16-hand range case has no reduction under this group.

Every orbit key contains global actor, own physical holding and full revealed
board/action history. Different betting histories sharing a vertex never merge.
The independent reviewer checks whole exported public-graph symmetry closure:
transformed decision/player/action menus and monetary fields, ordered chance
branches, and terminal kinds/winners/contributions must match. It also verifies
actual supported row/menu closure. This is stronger than comparing orbit counts,
but remains conditional on the exported graph. No regrets, averages or policies
are merged, no compressed policy format is trained, and no realized RAM saving
or CFR+ trajectory equivalence is claimed. An actual quotient still requires
reach/update/average proofs, storage admission, independent complete-policy/BR
replay and measured full-call costs, including identity-group overhead.

## Independent verification and limits

Before any structural calculation, the external reviewer authenticates all 1,828
current source files against captured raw SHA256 and committed raw/normalized Git
blobs, every raw artifact and the externally pinned archive. It imports no
repository module. It separately parses the concrete private ranges and ordered
boards, validates the exported graph schema/acyclicity/reachability and computes
capped path/depth/history/row/work bounds before expanding any histories.

For each of the sixteen accepted cases it independently enumerates only bounded
verification pair/board compatibility, derives blocker-conditioned hand support,
streams public histories, counts rows/slots/tokens/bytes/contexts and recomputes
the weighted suit group and orbit closure. It checks every report summary, axis,
zero-call counter, cap screen and raw hash. Current source and all study bytes
remain unchanged afterward. Its own bounds include 16 hands/seat, 48 boards,
250,000 public occurrences, two million modeled entries, 500 million work and
16 million history bytes; they are new structural-verification limits, not
increased limits of the existing quality certificate.

This proves **structure conditional on the authenticated public graph**, not
independent legal construction of each larger poker game. Separate physical/S4
oracles validate the two bounded controls, and earlier whole-game numeric/exact
certificates remain their own evidence. The displayed independent certificate
shape screen is only a conservative necessary-cap comparison; even passing it
does not prove full verifier input/work/bit admission or accuracy. No quality
oracle, production cursor, ranker, solver or kernel query executes in saved
structural replay. Pure-array bytes, UTF-8 token bytes and modeled overlapping
slots are distinct scopes; none is measured Python allocation, RSS or CPU.

Two reviewer-only failures are preserved: its first parser retained input order
instead of the admitted complete-outcome canonical ordering; its second used
supported row actions where the final producer screen declared the conservative
dense action upper bound. Both helpers/logs and repair histories remain. After
those corrections, all sixteen conditional structural replays pass and the
capacity rejection is retained. The producer batch was never rerun or altered.
Twenty-seven independent synthetic reviewer controls cover malformed priors,
cycles, duplicate branches, capped path/depth growth, shuffled canonical inputs,
