# Native four-street role traversal

The explicit research target now executes both target passes and commits two
signed vanilla-regret updates through the shared History, Catalog, Prepared
chance and sparse Store owners. It uses supplied deterministic Q52 action
tickets. It does not yet generate random learning trajectories. The scope is
the fixed four-street betting template and two-epoch lifetime, with
`quality_gate=null`.

This continues the [role-owner contract](opponent-role-epoch.md) and the
[independent conditional moment proof](opponent-action-moment-gate.md).
The original [phase profile](native-training-phase-profile.md) identified the
inclusive walk as the largest measured phase. Later read-family observation
and both failed arithmetic observers remain preserved in the
[CPU record](joint-thread-cycles.md). This change reduces executed branches;
it does not infer a helper-level bottleneck or claim equal-quality speed.

## Executed contract

Each target expands every own action, including actions with zero policy
mass, and selects one opponent action from the frozen Q52 policy using an
exact integer CDF. Separate target roles collect centered regrets and the
other player's average increments. Native code never constructs the global
proposal/reach product. Compact raw regret and average carriers remain
`2^365` and `2^52`; the existing Store retains its canonical `2^625` and
`2^364` scales and unchanged allocator.

The independent oracle uses literal complete action/reveal histories,
Fraction arithmetic, explicit own/opponent reach and proposal prefixes, and
the original streamed full1326 physical joint law. It verifies cancellation
rather than borrowing the native cancellation implementation. Both roots are
checked separately: sampled target roots need not be opposites. Metadata
transport ordinals do not replace the oracle's semantic history keys.

One active certificate is checked against the exact certificate bound by the
role lease. Another live chance owner with identical physical values cannot
authorize a walk. Native output remains private until both epochs and all
actual owner ledgers pass. Invalid headers/selectors/tickets reject before
card or tree preparation; missing/excess supplied tickets reject during the
walk and publish no partial output.

## Retained state is still a scaling gate

Sampling fewer branches does not imply a bounded long-run numerical store.
Average increments are nonnegative; every visited average role adds total
mass one on its declared carrier. Once positive, that average cannot vanish.
For a nonzero regret row R, let sigma be its own quantized regret-matching
policy. If R has a positive entry, sigma has support only on positive
entries, so `sigma dot R > 0`. Largest-remainder rounding cannot allocate
units to a zero-remainder nonpositive entry while a positive remainder
remains. If every entry is nonpositive, the uniform fallback has strictly
positive units on all actions, so `sigma dot R < 0`.

Erasing R requires delta=-R, whose policy dot product is nonzero. Valid raw
updates require `sigma dot delta=0`; therefore a nonzero numerical row
cannot become all zero under this coupled policy/update contract. This
argument depends on using R's own matching policy. For example R=(1,-1)
and an arbitrary uniform policy allow an erasing centered delta; that
foreign-policy counterexample is preserved in the independent controls.
All 772 nonzero vectors on `{-2,-1,0,1,2}^k`, k=2..4, pass the sign/support
control in both modes. This is a finite check of the argument, not a larger
lifetime admission.

Long-run retained state, a genuine random-stream contract, policy-dependent
encounter/variance behavior, convergence, visible-information saved-policy
quality and cost at equal quality remain open. The old eleven-card exhaustive
State/Quantizer/parent refusal remains unchanged. This full52 two-observation
path does not admit that exhaustive schedule or realistic unrestricted NLHE.
The next architectural decision must measure storage growth and useful
learning per unit cost before extending the lifetime or changing ownership.
