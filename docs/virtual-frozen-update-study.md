Status: preparation; the all-outcome producer has not run. This protocol covers
the complete [PROOF9/v1 game](virtual-frozen-update.md), not a reduced substitute
for that game. All 2,520 public boards under both proposal laws are required.
No outcome is discarded or redrawn because its physical target mass is zero.

## Current rank-free admission implementation

`tests/virtual_frozen_study_admission.py` visits every board for both laws,
retaining only totals, maxima and bounded prefix-probability sums. It creates
no reference update, candidate update, rank call or expanded physical row key.
All three controls pass normally and optimized; the
[development evidence manifest](../benchmarks/results/virtual-frozen-study-admission-development-v1/manifest.json)
retains both initial and hardened control runs.
The expected row-record count is 107,080 per law, 214,160 in total. Each law's
reference admission reserves 120 rank calls (60 compatible physical worlds).
The context is counted once across both laws.

The weighted proposal forecast uses unreduced positive ratios:
`(1,1)`, `(5*outside_flop_weight,12600)`,
`(outside_turn_weight,12600)`, `(river_weight,12600)`.
The board `[16,17,24,32,48]` simultaneously maximizes the three non-root
numerators at 195, 35 and 9. All denominators are fixed. Uniform ratios are
constant. Enumerating all boards verifies both numeric dominance and each
prefix's independence from hidden future cards. Python Fraction reduction
cannot establish an upper bound on these unreduced native widths.

The native forecast otherwise uses fixed, unfiltered template geometry, original
prior weights, maximum matched payoff, path depth and menu width. It does not
reduce work on zero-target boards. In the current source the proposal-dependent
terms are only bit widths of board/prefix numerators and denominators; they are
monotone in the quantities above. This source-level argument must be rechecked
at the exact frozen source revision. A later forecast change invalidates the
argument until reviewed.

No per-game cap is raised, and no cumulative owner meter is reset. Native logical

reported separately. The raw-output bound excludes requests, metadata, reference
exports and logs; it is not an admitted total disk/RSS bound. The aggregation,
q-free oracle and serialization envelopes remain required before execution.

## Failure controls and later obligations

Saved-only mutations should detect omitted or wrong q/d5, double prior or reach,
own past reach in regrets, opponent reach in averages, future-card pruning,
conditional redraw, zero-action omission, wrong global roles, row aliasing and
incorrect q(P). Every detector needs a real witness; preserve detection misses.
Existing bounded ownership/admission controls are separate from these numerical
mutations and whole-game equivalence.

This experiment proves a single fixed-profile update identity if accepted. It
does not supply an actual sampler, evolving-policy reach representation, bounded
persistent learning storage, convergence, complete policy exports or independent
whole-game best responses. Those remain part of the unchanged overall goal.
