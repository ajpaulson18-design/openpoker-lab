## Host preparation and diagnostics

The rank-free host profile reserves its real exact-kernel constructor/support,
direct public topology, visible information, expanded output, compact prior
snapshot, group search, public-graph automorphism proof and native transport.
Python training is never entered. Its diagnostic forecast retains three
action/hand marginal-fallback traversals and six terminal passes. Legal support
queries used to authenticate returned policy rows remain charged. Final actual
kernel, integer-payload, adapter and combined whole-request checks remain active.

Only the Python iteration-dependent training terms are absent: T decision
marginals, 2T terminal traversals, T packed numeric traversals and 3T semantic
history lookups. The Python equivariant trainer/layout and quotient-plan
construction are not executed or charged. Their native counterparts are charged
by the native ledger. Original R-sized geometry, output, history, depth and
conservative host storage reservations remain, including unused Python numeric
slots. Removing a work forecast does not establish a memory improvement.

The host reserves group search, graph proof and complete input/output buffers
before preparing those buffers. The wire transfers the remaining shared work
allowance to C++; it does not give each process a separate 500-million allowance.
Host retained/scratch admission keeps its existing 25-million logical-entry cap;
the native owner retains its existing two-million cap. These counts are not
allocator bytes, CPU bounds or process-memory guarantees.

V3's added proof scan has its own host work and scratch reservation: occurrence
and history processing, B-by-decision membership scans, one retained board-index
tuple per distinct decision prefix, current tuple overlap and fixed named-proof
dictionary/counter scratch. It is not assumed free because older reservations
were conservative.

## Native construction and learning

`graph::AdmissionProfile::indexed_v1` preserves physical hands, weighted suit
group, full graph closure, exact support, original Q keys, menus, offsets, masks
and retained histories. It retains the conservative eight-pass setup/output
envelopes and all other Plan preparation terms. It removes exactly the old
3T history-lookup and 6T action-check forecasts; the retained eight is a modeled
envelope, not a claim of eight literal API calls.

The trainer retains its numeric traversal/rematch terms, actual kernel
constructor/support and future callbacks, once-only cached marginal vectors,
four history setup/output passes, and the complete Index/Router query schedule.
Only the 3T legacy history forecast is removed. An indexed-profile Plan rejects
full-history or shadow training before training arrays grow. The existing
500-million work, two-million native-entry, integer-value/payload, geometry and
I/O caps still apply. Real callback growth can still reject a larger request.

V3 has a fixed-indexed request header
`OPENPOKER_NATIVE_EXACT_FOUR_STREET_INDEXED_ADMISSION_V3`; it has no routing token.
Its result header is
`OPENPOKER_NATIVE_EXACT_FOUR_STREET_INDEXED_ADMISSION_RESULT_V3`, followed by the
existing complete ROW/DONE/ROUTE records and a bounded `ADMISSION indexed-v1`
record. V1/V2 grammars remain separate.

Python independently derives the removed lookup/action/history terms from legal
occurrence histories and checks once-only marginal-key reuse. The named work
components must satisfy:

```
combined = Plan setup + Index setup + Router setup
         + Router query forecast + Index query forecast + caller
```

The same combined work/entries must match ROUTE and DONE and fit the host's
remaining reservation. Missing, duplicate, malformed, forged or crossed-version
proofs reject. A receipt validates accounting/structure; independent policy and
best-response replay remain separate mathematical evidence.

Direct V3 transport also requires its existing internal host reservation; work
or entries above the reserved remainder reject before native invocation. The
internal preparation dictionary is mutable trusted orchestration state, not a
capability intended to resist a caller deliberately altering internal objects.

keeps actual marginal-cache keys restricted to decisions, with an explicit bounded
prefix-set reservation. A compiled regression matches the Python reference and
protected replay. The runner also recognizes the two exact positive budget-floor
messages that stopped its parent classifier. These are post-freeze corrections;
they do not rewrite the original study. The corrected API/independent/runner
suite passes 32 controls with assertions disabled (26.925 seconds).
