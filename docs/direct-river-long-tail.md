# Longer explicit direct river-tail budgets

The separate [river direct-tail API](direct-river-tail.md) accepts explicit
integer `iterations` from 10 through 100,000, subject to every existing work
guard. The default remains 1,000. Requests through 10,000 keep the literal v1
payload; requests above 10,000 use
`research-river-long-tail-adapter-v1`. The longer request itself selects this
result version. It adds no stopping mode or convergence promise.

This is a river-only admission extension. The shared local CFR+ accumulator,
tree, world normalization, hand indexing, response diagnostics and original
linear tail weights remain unchanged. Turn and ordinary postflop retain their
10,000 ceilings. Existing saved policies, report hashes and verification sources
remain immutable. The preceding [fixed two-game experiment](direct-river-tail-experiment.md)
retains its polarized miss and weighted meet.

## Full-request guards

Every candidate and physical-world iteration limit continues to use full T.
The same public-state/node, prefix-edge and one-million action-slot caps apply.
The 30-million world-node and dense hand-state-pass limits remain independent:

| Frozen game at T=100000 | World-node charge | Dense charge | Outcome before training |
| --- | ---: | ---: | --- |
| Polarized | 2,400,000 | 5,400,054 | Admitted by these guards |
| Weighted raises | 21,600,000 | 30,600,306 | Dense limit rejects |

Large discard does not rebate any admission charge: the weighted request still
rejects with D=99999. These modeled charges are not runtime or RSS bounds.

## Validation and limitations

The source change only makes the river ceiling local and selects a distinct
long-request version. Three whole canonical v1 payloads captured before this
change remain byte-identical to the frozen original on the same interpreter:
one-bet zero-discard, weighted raises with a
positive tail, and a dead-hand-index blocker case retaining the final sweep.

A genuine T=10001,D=3000 call on the frozen stack-100 polarized fixture passes
independent numeric rule/visible-information response replay for all eight
metrics and exact binary64 row-normalized five-terminal-history 16/4-response
evaluation. The legal interval contains the known value 25. Tests preserve all
previous finite diagnostics, local-state, flow and admission coverage, and
confirm the unchanged turn rejection at 10001.

The 100k one-bet admission test replaces the trainer with an explicitly labeled
test stub; it checks full request arguments and counters, not 100k quality.
The real weighted 100k request rejects before the trainer. No 100,000-sweep
direct-tail policy or accuracy result is supplied by this API slice. A future
quality experiment requires its own committed source freeze, raw policy,
independent numeric/exact audits and preserved target outcome.

All 31 integrated adapter/benchmark tests passed in 3.640 seconds; the 14
adapter tests also passed under optimized Python in 3.022 seconds. Existing
accepted river and turn bundles reconstructed with their nine/seven training
entry points disabled in 12.656 seconds after the producer change. Documentation
validation passed (140 files, 658 local links, 12 entry points).
Existing longer full-average matrix-free
river evidence is [separate](river-long-budget.md): a different backend and
averaging window do not predict the direct-tail outcome.

The first Python 3.11 CI run rejected two output hashes captured under local
Python 3.12.14. Parity now compares entire canonical payload bytes against
the exact pre-change API source from `0740199bd64bc9ef661e8fa1634972472fca405c`
on each interpreter. The reference source itself is SHA256 pinned. This keeps
strict within-runtime equality and the independent mathematical checks; it
does not assume identical floating-point output across Python versions.
The revised 31-test set passed locally in 2.344 seconds; all 14 adapter tests
also passed under optimized Python in 1.898 seconds.

The separate [fixed 100k experiment](direct-river-long-tail-experiment.md) defines
the committed-source call, raw-policy storage and independent exact quality
gates. Its actual result remains separate from this admission/API evidence.
