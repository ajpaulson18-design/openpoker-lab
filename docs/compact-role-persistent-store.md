# Compact persistent integers in the shared role Store

The explicit compact research target now retains smaller R/A integers in
the same sparse Store that already owns all policies. It keeps the canonical
default and the fixed two-epoch lifetime. Exact native state comparison,
historical-default byte parity, independent saved replay and a frozen
same-policy complete-call cost study pass locally. Cross-platform status
must be verified separately before broader acceptance.

This implements the boundary selected by the
[lossless representation audit](opponent-role-persistent-storage.md),
continuing the [full four-street role walk](opponent-role-four-street-walk.md).
It does not add a separate policy map, raise solver limits, enable random
training, extend learning or establish saved-policy quality.

## Same authority, explicit arithmetic

`PersistentCarrier::compact` binds the existing Store to
`weighted_joint_role_compact`: retained R and A use `2^365` and `2^52`.
The canonical contract still uses `2^625` and `2^364`. Both retain signed
vanilla regret, exact nonnegative averages, the same Q52 allocator/tie order,
full History/actor/original-holding identity, chance-owner binding and
callback/token lifetime. The facade still authorizes separate target roles
and checks regret centering and exact frozen-policy averages before stage.
Unknown modes and incompatible read/scale contracts reject explicitly.

For this fixed template, raw R has at most 370 bits and two-step cumulative
R at most 371; cumulative A has at most 54 bits. The Store checks those
narrower bounds. It retains the old conservative canonical work/payload
forecasts and the unchanged 704-bit Quantizer allowance. Its existing
`Entry` and vector structure remain; this is smaller integer magnitude,
not a packed arena or a smaller `sizeof(Entry)` claim.

Representation equivalence follows by induction. Initially both policies
are the same implicit uniform defaults. If frozen policies agree, supplied
tickets select identical opponent actions, own actions all remain expanded,
and both passes produce identical raw updates. Multiplying compact R/A by
`2^260`/`2^312` gives canonical state exactly after addition. Positive common
scaling preserves every exact regret-matching quotient, remainder and tie,
so the next policies agree. Narrow bounds follow from the two-step raw
limits; no coordinate is truncated or repaired on overflow.

New observation wrappers emit the same canonical numeric payload. Compact
export expands one coordinate at a time; it does not retain a second
canonical policy image. Expansion has an explicit parent charge of 512 per
snapshot plus 98 per slot; used/capacity observation charges 512 plus 64 per
slot in both variants. The old fixed scratch envelope of 8,810 bit cells
covers the sequential exporter temporary of at most 1,966 bit cells. The
extended frame's exact worst byte count 542,272 remains below the original
549,280-byte output reservation.

| Complete native request model | Canonical observer | Compact observer |
| --- | ---: | ---: |
| Work | 124,568,156 | 124,809,084 |
| Parent work | 3,003,564 | 3,244,492 |
| Entries | 978,410 | 978,410 |
| Payload bit allowance | 49,838,772 | 49,838,772 |
| Output byte allowance | 549,280 | 549,280 |

The original non-observer default remains at 124,410,460 modeled work with
the original protocol and complete bytes. The compact modeled work bound is
higher because canonical export is explicitly billed; no accounting-based
capacity gain is claimed. These are logical conservative ledgers, not CPU
instruction or physical-memory measurements.

## Observed integer backend storage

These Windows builds use 32-bit backend limbs. Across 24 snapshots from
twelve separate experiments and both epochs:

| Native R/A backend observation | Canonical | Compact |
| --- | ---: | ---: |
| Used limbs | 23,074 | 9,238 |
| Capacity limbs | 29,792 | 16,192 |

For the first repeated-world case's second snapshot, capacity is 2,696
versus 1,356 limbs at the same 36 rows/117 slots. Used limb counts are
independently derived exactly from signed values and the declared limb size,
including zero representations. Capacity values are authenticated original
native observations with plausibility bounds. They include inline/backend
capacity; they must not be added to object sizes to infer heap bytes or RSS.
Maps, vectors, descriptors, output buffers and allocator overhead remain
separate. The aggregate spans repeated epochs and independent policies,
not one combined retained policy or a long-run occupancy forecast.
