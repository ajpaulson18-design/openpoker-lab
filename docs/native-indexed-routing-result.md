# Indexed native learning: frozen results

The [explicit indexed backend](native-indexed-routing.md) removes repeated full
history construction, legacy Q lookup and prefix parsing from learning. Exact
numeric Q keys preserve old indices/order/menus/offsets/member masks and support
holes. Old preflight, marginal/Q setup, Q histories and expanded diagnostics remain.
The full-history default and differential shadow mode remain available.

## Two complete committed-source batches

Each fixed batch completes all twenty prescribed fresh children without retry:
eight full-history/indexed pairs, two shadow checks and both original T1000
pre-training rejections. Eighteen complete policies receive fresh independent
numeric/exact saved-only replay. All ten within-batch policy/eight-metric/exact
certificate pairs match, with the unchanged quality gate retaining sixteen misses
and two private-flush T100 passes. Maximum independent numeric gap is
8.326672684688674e-17. Rejected requests have no quality result.

are a separate scope. No total-memory reduction or general speedup is established.

## Independent evidence and representation

Each saved-only reviewer authenticates all 2,070 raw/Git source files, the complete
eleven-input native build closure, all 198 extracted dependency headers and every
artifact before mathematical replay, then checks stability again afterward. Review
invokes no candidate/trainer. Independent numeric rules, best-five ranking and exact
visible-information best responses evaluate each complete saved policy; policies,
menus, probabilities and all eight diagnostic bits are compared between modes.

The reviewer independently parses V1/V2 ROW and DONE13, derives unfolded graph
counts from the native input, checks weighted suit stabilizers/Q orbits, and checks
all routed fields against complete-call schedules. This is not an independent
equivalence proof for the entire native input graph. Earlier accepted physical-game
and all-in-tail evidence remains separately scoped; final-policy replay and wire
census checks must not be promoted to an unperformed graph proof. A separate
cross-source review confirms all eighteen policy/menu/probability/metric bits and
exact certificate identities, without comparing timings.

Actual-call instrumentation on a separate bounded support-hole fixture finds
learning calls `[extend_history, locate_decision_rows, prefix_board_indexes,
revealed_cards, transform_history]` equal `[60,30,50,190,30]` in legacy and shadow
modes and `[0,0,0,0,0]` in indexed mode. All three Q policies match bitwise. Exact
source copies, anchor diffs and raw compiler/run streams are preserved. This is
dependency-removal evidence on that fixture, not independent poker quality or timing.

The original fixture still has 1,200 physical/Q rows and 2,402 Q action slots with
identity stabilizer. Numeric routing adds Q-sized metadata and retains existing Q
histories. It introduces no expanded R lookup or private-pair/world table. Four Q
learning arrays and the old numerical trajectory remain. All fixed 24-image/slot
arrays, simultaneous cursor frames, query schedules and caller work are admitted
together. Old history work and named kernel forecast overlap remain conservatively
charged: this result does not open the larger original T1000 request.

## Separate Windows native-process observations

After the timing batch ended, four separate native-only processes received the
saved original/mixed full-history/indexed inputs. Every stdout matched its frozen
counterpart. OS memory queries ran during each process lifetime and recorded the
Windows working-set high-water through the last successful query. Original-22
reported 5,414,912 bytes in both modes; maximum sampled private commit was
2,629,632/2,682,880 bytes full-history/indexed. There were 53/17 successful queries
for that pair. The small mixed fixture had only 3/2 queries and cannot support a
reliable peak comparison.

This is neither native heap measurement nor complete simultaneous Python/native
memory. A late process peak after the last poll could be missed; sampled private
commit is not a peak guarantee. No memory-reduction conclusion follows. Raw queries,
input/output bindings, source authentication and the probe helper are archived.

## Retained failures, scope and publication

Strict GCC rejected the original unused constructor iterator with `-Werror`.
Root's first fix deleted a similarly named query iterator, which MSVC rejected;
that committed intermediate source and compiler failure remain. The corrected
source differs cumulatively only by removing the unused constructor declaration.
No warning was disabled. Original, intermediate and corrected records are distinct.

Other preserved failures include the uninitialized MSVC environment in a direct
control run, stale-build rejection after a source edit, ambiguous comparator
initializer-list overloads, wrong working-directory build and runner smoke paths,
and a reviewer-only receipt decoding error. Earlier Luna v1-v6 raw streams were not
captured separately; the development inventory explicitly records this and other
capture gaps. Sol's last final review was usage-limited; completed implementation,
Terra scrutiny and root checks do not imply an unavailable final Sol acceptance.
