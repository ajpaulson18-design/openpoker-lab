# Persistent role-state representation gate

The exact [native role walk](opponent-role-four-street-walk.md) commits
compact raw updates through the existing Store, whose persistent integers
still use the earlier full-walk canonical scales. The [complete-call cost
study](opponent-role-walk-cost.md) passes its scoped cost rule with substantial
dispersion. Longer training is still blocked by explicit lifetime/resource
contracts and retained-state growth. This audit selects a lossless storage
candidate before changing that shared owner.

## Original lossless audit

Source `733c7b8bac3a80e27d81dc1759eb90b940fd523c` captures 57 complete
Python files before mathematical imports. Each run first authenticates the
original whole-walk packet and independently replays all twelve native cases
and 6,780 numeric coordinates. It then checks both committed snapshots per
case: 460 row occurrences, 1,226 action slots and 2,452 R/A coordinates across
24 snapshots. These totals add separate experiments and epochs, rather
than describe one combined trained policy.

Every R coordinate is exactly divisible by `2^260`, every A coordinate by
`2^312`. Division gives compact scales `2^365`/`2^52`; re-expansion restores
every signed value exactly. No truncation, rounding, negative average,
policy substitution or averaging-law change is allowed. Observed compact
widths reach 370/53 bits. Four malformed alignment/sign/width examples reject.
Both Python modes succeed with identical reports, SHA256
`ab480f15b948975aba1af2f2611d2e010e7a7eb0a416e1dc7d9583c35e61157a5`.

The exact removed padding is 437,216 bit cells, equal to
`260*532 + 312*958` for the nonzero R/A coordinates. That is 64.25% of
integer magnitude payload and 25.70% of the unchanged-descriptor logical row
model. Descriptors remain substantial. These are representation models;
they do not measure allocator capacity, object overhead, peak memory/RSS
or runtime, and cannot forecast a million-observation policy from twelve
deterministic traces. The existing Store is unchanged.

## Next implementation boundary

Keep the existing Store as the single numerical policy authority. Introduce
compact persistent representation only through an explicit contract that
rejects foreign arithmetic/role/owner combinations before allocation. Keep
the old canonical contract and all historical evidence replayable. Do not
install a second independent policy map behind a facade or silently choose
a fallback based on an input that fails admission.

Compact storage must preserve signed vanilla regret, exact nonnegative
averages, Q52 tie order, full History/actor/original-holding identity, hidden
future information, selected-world certificate binding and callback/token
lifetime. Centered raw updates must still be checked against the frozen
policy. Changing numeric carriers does not authorize deleting nonzero rows;
the [retention argument](opponent-role-four-street-walk.md#retained-state-is-still-a-scaling-gate)
continues to apply.

Before native allocation, independently derive complete Store/cache/History/
Catalog/chance/staging/quantization/export and temporary-conversion bounds
under the existing caps. The verified row component is an arithmetic
building block; it does not independently authorize poker identity or
ownership. Quantizer effective division widths already match after common
power cancellation, so removing padding is not a division-speed claim.

Acceptance requires native all-row equality after exact canonical expansion,
both roots, all evolving policies and role ledgers, failure/private-output
guards, preserved original source/process evidence, saved-only replay and
Windows/Linux/sanitizer execution. Measure actual native ownership/layout
and a predeclared complete-call comparison before a memory/runtime claim.
Keep the two-epoch lifetime unchanged while integrating representation;
derive a separate longer-run schedule and independent quality acceptance
afterward. The old eleven-card exhaustive refusal remains unchanged.
