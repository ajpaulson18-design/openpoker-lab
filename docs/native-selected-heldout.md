This [complete evidence receipt](../benchmarks/results/native-selected-heldout-v1/receipt.json)
extends validation beyond the [original native comparison](native-selected-operator.md).
It does not establish a larger exact quality pass. All original limits remain.

At clean source `745e4dd48614673dbc6372025d30cdb6bb35f3af`, Luna ran one fresh,
untraced T100 call per backend on a distinct two-flop, six-runout, four-hand-per-seat
game representing 96 compatible physical worlds. Both paths use packed storage
and rank-cache capacity 64. Complete strategies, five numeric diagnostics and
private-pair probabilities are identical. Independent saved numeric replay has
maximum discrepancy about 1.11e-16. Source and native build identities remain
unchanged; scripts, full policies, failures and manifests are archived.

Single complete calls took 16.018 seconds Python and 0.605 seconds native.
These are observations without a runtime distribution. Parent Python and child
native process peaks are separate; this experiment includes no allocation trace
and establishes no memory saving.

Both complete 2,224-row policies are rejected by the exact certificate's existing
2,048-row input limit. This is an unexecuted exact audit, not an exact target
pass or mathematical disagreement. Numeric NashConv is approximately
0.002056985987057891 BB, above the earlier 0.001 BB target. T1000 rejects the
unchanged 500-million scan envelope before training. No retry, row truncation,
limit change or smaller substitute is used to produce a passing certificate.

## Next representation decisions

Terra's review finds a safe same-game candidate in shared immutable betting
templates with lazy traversal cursors. The existing builder makes temporary
templates but clones every branch into a full-history tree, followed by a second
shifted training view. A factored topology must preserve each full observable
history, global seat identity, local monetary rounding, legal chance partition
and distinct information-set rows. Equal pots/stacks do not justify merging
strategy rows. Quantify unique retained templates and expanded logical visits
separately, and admit complete output/traversal work before allocation.

Removing private-pair scans also needs a numerical-law decision. Terra supplies
a concrete nonzero-determinant example: the legacy individually rounded pair
matrix is not always separable into per-hand factors. The archived
[numerical review](../benchmarks/results/native-selected-heldout-v1/numerical-factorization-review.md)
records the counterexample and proof obligations for an explicitly versioned
exact-weight law. Inclusion-exclusion and rank-group sweeps are candidates;
neither the full-deck mass prototype nor ranked river normalization is a drop-in
selected four-street trainer. No new numerical law or topology backend is
implemented or activated by this evidence publication.
