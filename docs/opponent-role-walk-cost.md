# Complete-call cost of the deterministic role walk

The [native role walk](opponent-role-four-street-walk.md) passes a frozen
complete-call cost comparison against the current-source single-global full
walk. This compares different deterministic two-epoch estimators and output
sizes on the same physical selector schedule. It does not establish equal
quality or convergence speed.

Controller `5606fdd0f3ed7eb3aab986df1fcc9286b907ad92` captures all 91
introduced source files before numerical imports or observations. Both
executables use the same MSVC19.44 compiler and integer dependency, with
identical optimization/warning flags; the full comparator additionally
requires its exact weighted-two-epoch and single-pass target macros.
Current raw source matches each complete build manifest. The comparator was
an existing build, authenticated against the benchmark's captured current
source closure; it was not rebuilt for this study.

The schedule contains four weighted full1326-range cases: repeated tie,
SB loss, SB win, and a shared board with a changed opponent holding. The
role tapes are first, alternating, middle and alternating respectively.
Eight warmups independently verify every retained R/A/policy coordinate for
each estimator using its own current mathematical oracle. Every timed
process must then reproduce its estimator's complete warmup wire exactly.
There is no cross-estimator numeric equality requirement: a sampled update
and the full conditional update are different objects.

Eight alternating-order pairs each execute eight calls per estimator,
using identical four-case order within a pair. All 136 actual processes
exit zero with no stderr or automatic retry. Timing includes process
startup, full range/template setup, both updates, private output and
transport. It includes the distinct amounts of raw/state output generated
by each algorithm. The fixed cost rule was median ratio at most 0.95 and
at least six faster pairs, recorded before any timing collection.

Median ratio is 0.460285 and seven pairs are faster, so the original cost
rule passes. Dispersion is large: the last pair is substantially slower,
and the full range is 0.089345..2.852288. These short complete calls were
observed on one Windows host with uncontrolled other load. Preserve every
pair and do not use the median as a stable throughput multiplier, a
helper-level attribution, a production forecast or a claim about time to
equal independently measured solver quality.

Both initial pre-observation refusals are preserved. The first supplied an
older comparator whose source hashes had drifted; it launched no native
calls. The replacement comparator matches all current source hashes. The
second refusal caught a checker that declared only one of the comparator's
two required target macros; it also launched no native calls. The corrected
contract requires both exact macros, while optimization/warning flags and
the numerical/performance acceptance rules remain unchanged.

The separate [immutable packet](../benchmarks/results/opponent-role-cost-v1/manifest.json)
retains all 136 processes, full warmup and timed policies, every observed
duration, original requests, both refusals and source/build/invocation
closure. Manifest SHA256 is
`b4499d504aa13a609849b857b9f5a3b4b8673dceb7d69e2625040b5123f4e1bb`.
One hundred exact shared objects occupy 4,236,105 stored expanded bytes
under the original 80-MiB packet cap. The saved checker authenticates all
of this before numerical imports, replays all four cases separately for
both estimators, and recomputes each timing pair from original process
receipts. It executes neither native binaries nor archived code. Original
saved replay passes in both Python modes at reader
`7970c6d`; their reports are byte-identical with SHA256
`66055222d8271a49d5b2e26539d5a13552d98fceef3a46acddf1e0a97b5099a8`.
This success does not remove the observed timing dispersion.

Together with original exact native parity and the unchanged complete
request forecast, this warrants retaining the role traversal as an explicit
foundation path. It does not warrant changing the default, extending the
two-epoch lifetime, claiming eleven-card exhaustive admission or declaring
a realistic heads-up NLHE game solved. Next resolve bounded persistent
state and random-stream ownership, with independent saved-policy quality
and cost at equal quality as later acceptance gates. Do not tune these
short-call timings to obtain a larger percentage.
